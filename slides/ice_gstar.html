ICE: exact memory for language models without attention

Recurrent LMs (Gated DeltaNet) are cheap: their memory has a fixed size. But they forget exact details, like a config value seen 2,000 tokens ago. Hybrids add attention back, and its cache grows with every token.

Limitations

Changed values: with an old version of a file in context, ICE copies the old name 65% of the time (hybrid 13%). Short training: the lead over the hybrid narrows as training goes on.
